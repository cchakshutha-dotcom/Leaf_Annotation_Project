# Leaf Annotation Project

## Overview
This project is an AI-based leaf annotation and plant disease analysis system using Computer Vision and Machine Learning techniques.

The project helps in identifying and annotating leaf regions for disease detection and analysis.

---

## Features
- Leaf image annotation
- Plant disease analysis
- Dataset preparation
- Model training using YOLOv8
- Prediction on leaf images
- Data splitting for training and testing

---

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Machine Learning
- Computer Vision

---

## Project Structure
- `train.py` → Model training
- `predict.py` → Prediction on images
- `prepare_dataset.py` → Dataset preparation
- `split_data.py` → Dataset splitting
- `data.yaml` → Dataset configuration
